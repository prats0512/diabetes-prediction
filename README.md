# Diabetes Prediction using Machine Learning and MLP

## Overview

This project predicts whether a patient is diabetic using the Pima Indians Diabetes Dataset. It includes complete data preprocessing, exploratory data analysis, feature engineering, multiple machine learning models, a Multilayer Perceptron (MLP), hyperparameter tuning, and Gradio deployment.

## Models Implemented

- Logistic Regression
- K-Nearest Neighbors
- Support Vector Machine
- Random Forest
- Multilayer Perceptron (TensorFlow)

## Best Model

| Model | Accuracy | ROC-AUC |
|--------|----------|---------|
| Random Forest | **86.36%** | **0.9469** |
